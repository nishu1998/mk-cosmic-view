🌌 Cosmic View

Cosmic View is an Android application that brings astronomy and space exploration closer to users by leveraging multiple NASA public APIs.
The app provides daily space imagery, asteroid data, space galleries, and upcoming astronomical events in a clean and intuitive interface.

🚀 What started as a college project has been polished into a Play Store–ready Android application.

📱 App Overview

Cosmic View allows users to explore space through:

NASA’s Astronomy Picture of the Day (APOD)

Near-Earth Object (Asteroid) tracking

A searchable space image gallery

A curated list of upcoming astronomical events

The app is designed for space enthusiasts, students, and anyone curious about the universe.

✨ Features
🪐 Astronomy Picture of the Day (APOD)

Displays NASA’s daily featured space image

Includes official descriptions and explanations

Updates automatically every day

☄️ Near-Earth Objects (Asteroids)

Shows asteroids passing close to Earth

Displays size, distance, and hazard classification

Uses NASA NeoWs (Near Earth Object Web Service)

🖼️ Space Image Gallery

Browse and search high-quality NASA images

View images in full-screen mode

Download images locally to the device

📅 Upcoming Astronomical Events

Curated list of upcoming celestial events

Includes meteor showers, eclipses, and planetary events

Designed for easy readability (static data in the current version)

🏗️ Architecture & Design

The app follows modern Android development best practices:

MVVM Architecture

Repository Pattern for data handling

Clear separation of UI, business logic, and data layers

Lifecycle-aware components using ViewModels

This structure makes the app scalable and maintainable for future versions.

🛠️ Tech Stack

Language: Kotlin

Architecture: MVVM

Networking: Retrofit

Image Loading: Glide

APIs:

NASA APOD API

NASA NeoWs API

NASA Image Library API

Tools: Android Studio, GitHub, Google Play Console
